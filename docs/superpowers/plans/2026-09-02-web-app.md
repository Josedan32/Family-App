# Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Phase 1 web client — a mobile-first, installable PWA for iOS Safari that covers all eleven Phase 1 screens, and is the surface where the visibility model becomes something a family member can actually understand.

**Architecture:** Next.js App Router. **Tokens live in httpOnly cookies set by Next.js route handlers, never in `localStorage`.** Reads behind visibility rules happen in Server Components using the caller's token, so data the viewer may not see never reaches their browser at all — defence in depth behind the API's own enforcement. Client mutations go through a thin proxy route handler that attaches the cookie token. TanStack Query owns client-side mutation state; there is no global state library.

**Tech Stack:** Next.js 15 (App Router) · TypeScript · Tailwind CSS · TanStack Query · Vitest + Testing Library · Playwright · `openapi-typescript` for the generated client

**Spec:** `docs/superpowers/specs/2026-09-02-family-hub-design.md`

**Depends on:** Plans 1–3. The API must be running and migrated.

**Also read before starting:** **`docs/design-system.md` in full** — it exists because iOS Safari has sharp edges that desktop-first development does not reveal. Then `docs/api-contract.md` for response shapes and `docs/glossary.md` for Spanish copy.

## Global Constraints

- **UI strings are Spanish (`es-CO`). Code, identifiers, comments and commits are English.** Translate through `docs/glossary.md`.
- **`100dvh`, never `100vh`.** On iOS Safari `100vh` excludes the toolbar and the bottom of every full-height screen ends up underneath it.
- **Respect safe areas:** `env(safe-area-inset-bottom)` on the bottom nav, `env(safe-area-inset-top)` on the header.
- **44 × 44 px minimum touch targets.** Applies to icon buttons, which are the ones that get this wrong.
- **Inputs are at least `16px`** or iOS zooms on focus and never fully recovers.
- **No hover-only affordances.** Touch has no hover.
- **The client never does arithmetic on money.** It formats `amount_minor` integers; every total comes from the server.
- **A private module renders `PrivateBlock`** — a muted "Privado" panel. **Never a blurred number, a skeleton, or `$—`.** A blurred figure invites guessing at a magnitude; a skeleton implies data is loading and will arrive.
- **API responses are never cached to disk by the service worker.** A cached financial response outlives the visibility setting that permitted it.
- **Tokens never touch `localStorage`.** httpOnly cookies only.
- **The generated API client is never hand-edited.** CI fails if regenerating produces a diff.
- **Colors come from semantic CSS custom properties.** No component references a raw hex value.
- **Commits:** `<type>(<scope>): <subject>`, imperative, ≤ 50 chars, no trailing period.

Create `apps/web/src/lib/session.ts`:

```ts
import { cookies } from "next/headers";

/**
 * Tokens live in httpOnly cookies, never in web storage.
 *
 * A refresh token in localStorage is readable by any script that gets injected
 * into the page. httpOnly means the browser will send it and JavaScript cannot
 * read it.
 */

const ACCESS = "fh_access";
const REFRESH = "fh_refresh";

const BASE = {
  httpOnly: true,
  secure: process.env.NODE_ENV === "production",
  sameSite: "lax" as const,
  path: "/",
};

export async function setSession(access: string, refresh: string): Promise<void> {
  const jar = await cookies();
  jar.set(ACCESS, access, { ...BASE, maxAge: 60 * 15 });
  jar.set(REFRESH, refresh, { ...BASE, maxAge: 60 * 60 * 24 * 30 });
}

export async function clearSession(): Promise<void> {
  const jar = await cookies();
  jar.delete(ACCESS);
  jar.delete(REFRESH);
}

export async function getAccessToken(): Promise<string | undefined> {
  return (await cookies()).get(ACCESS)?.value;
}

export async function getRefreshToken(): Promise<string | undefined> {
  return (await cookies()).get(REFRESH)?.value;
}
```

- [ ] **Step 6: Write the server fetch**

Create `apps/web/src/lib/api/server.ts`:

```ts
import { ApiError, type Problem } from "./errors";
import { getAccessToken, getRefreshToken, setSession } from "../session";

const BASE_URL = process.env.NEXT_PUBLIC_API_BASE_URL ?? "http://localhost:8000/api/v1";

async function request<T>(path: string, token: string | undefined, init?: RequestInit): Promise<T> {
  const response = await fetch(`${BASE_URL}${path}`, {
    ...init,
    headers: {
      "Content-Type": "application/json",
      ...(token ? { Authorization: `Bearer ${token}` } : {}),
      ...init?.headers,
    },
    // Financial data is never served stale.
    cache: "no-store",
  });

  if (response.status === 204) return undefined as T;

  const body = await response.json().catch(() => null);
  if (!response.ok) {
    throw new ApiError(
      (body as Problem) ?? {
        type: "unknown",
        title: "Ocurrió un error",
        status: response.status,
      },
    );
  }
  return body as T;
}

/**
 * Server-side fetch with one transparent refresh attempt.
 *
 * Reads behind visibility rules happen here, in Server Components, so data the
 * viewer may not see never reaches their browser at all.
 */
export async function apiFetch<T>(path: string, init?: RequestInit): Promise<T> {
  const access = await getAccessToken();
  try {
    return await request<T>(path, access, init);
  } catch (error) {
    if (!(error instanceof ApiError) || error.status !== 401) throw error;

    const refresh = await getRefreshToken();
    if (!refresh) throw error;

    const pair = await request<{ access_token: string; refresh_token: string }>(
      "/auth/refresh",
      undefined,
      { method: "POST", body: JSON.stringify({ refresh_token: refresh }) },
    );
    await setSession(pair.access_token, pair.refresh_token);
    return await request<T>(path, pair.access_token, init);
  }
}
```

```ts
import { NextResponse } from "next/server";

import { ApiError } from "@/lib/api/errors";
import { clearSession, getRefreshToken, setSession } from "@/lib/session";

const BASE_URL = process.env.NEXT_PUBLIC_API_BASE_URL ?? "http://localhost:8000/api/v1";

export async function POST(request: Request) {
  const { action, ...payload } = await request.json();
  const path = action === "register" ? "/auth/register" : "/auth/login";

  const response = await fetch(`${BASE_URL}${path}`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload),
  });
  const body = await response.json().catch(() => null);

  if (!response.ok) {
    return NextResponse.json(body, { status: response.status });
  }

  await setSession(body.access_token, body.refresh_token);
  return NextResponse.json({ ok: true });
}

export async function DELETE() {
  const refresh = await getRefreshToken();
  if (refresh) {
    await fetch(`${BASE_URL}/auth/logout`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ refresh_token: refresh }),
    }).catch(() => undefined);
  }
  await clearSession();
  return NextResponse.json({ ok: true });
}
```

Create `apps/web/src/app/api/proxy/[...path]/route.ts`:

```ts
import { NextResponse } from "next/server";

import { apiFetch } from "@/lib/api/server";
import { ApiError } from "@/lib/api/errors";

async function forward(request: Request, path: string[], method: string) {
  const url = new URL(request.url);
  const target = `/${path.join("/")}${url.search}`;
  const body =
    method === "GET" || method === "DELETE" ? undefined : await request.text();

  try {
    const data = await apiFetch<unknown>(target, { method, body });
    return NextResponse.json(data ?? { ok: true });
  } catch (error) {
    if (error instanceof ApiError) {
      return NextResponse.json(
        { type: error.type, title: error.message, status: error.status },
        { status: error.status },
      );
    }
    throw error;
  }
}

type Ctx = { params: Promise<{ path: string[] }> };

export async function GET(request: Request, ctx: Ctx) {
  return forward(request, (await ctx.params).path, "GET");
}
export async function POST(request: Request, ctx: Ctx) {
  return forward(request, (await ctx.params).path, "POST");
}
export async function PATCH(request: Request, ctx: Ctx) {
  return forward(request, (await ctx.params).path, "PATCH");
}
export async function PUT(request: Request, ctx: Ctx) {
  return forward(request, (await ctx.params).path, "PUT");
}
export async function DELETE(request: Request, ctx: Ctx) {
  return forward(request, (await ctx.params).path, "DELETE");
}
```

```ts
  const response = await fetch(`/api/proxy${path}`, {
    ...init,
    headers: { "Content-Type": "application/json", ...init?.headers },
  });

  if (response.status === 204) return undefined as T;

  const body = await response.json().catch(() => null);
  if (!response.ok) {
    throw new ApiError(
      (body as Problem) ?? { type: "unknown", title: "Ocurrió un error", status: response.status },
    );
  }
  return body as T;
}
```

```ts
/**
 * FORMATTING ONLY.
 *
 * The client never does arithmetic on money. Every total comes from the server,
 * computed in integers. JavaScript numbers cannot represent 0.1 exactly, so a
 * total summed here would eventually disagree with the one summed there.
 */

const MINOR_UNITS: Record<string, number> = { COP: 0, USD: 2, EUR: 2 };

/** U+2212, not a hyphen. */
const MINUS = "−";

function fractionDigits(currency: string): number {
  return MINOR_UNITS[currency.toUpperCase()] ?? 2;
}

export function formatMoney(amountMinor: number, currency: string): string {
  const digits = fractionDigits(currency);
  return new Intl.NumberFormat("es-CO", {
    style: "currency",
    currency,
    minimumFractionDigits: digits,
    maximumFractionDigits: digits,
  })
    .format(amountMinor / 10 ** digits)
    .replace(/\s/g, "");
}

export function formatSigned(
  amountMinor: number,
  currency: string,
  kind: "income" | "expense",
): string {
  const formatted = formatMoney(amountMinor, currency);
  return kind === "income" ? `+${formatted}` : `${MINUS}${formatted}`;
}

/** Digits only. Grouping separators, currency symbols and words are discarded. */
export function parseAmountInput(raw: string): number {
  const digits = raw.replace(/\D/g, "");
  return digits === "" ? 0 : Number.parseInt(digits, 10);
}

export function groupDigits(amountMinor: number, currency: string): string {
  const digits = fractionDigits(currency);
  return new Intl.NumberFormat("es-CO", {
    minimumFractionDigits: digits,
    maximumFractionDigits: digits,
  }).format(amountMinor / 10 ** digits);
}
```

```tsx
"use client";

import { useRouter } from "next/navigation";
import { useState } from "react";

import { Button } from "@/components/ui/Button";
import { Input } from "@/components/ui/Input";
import { clientFetch } from "@/lib/api/client";
import { ApiError } from "@/lib/api/errors";

type Mode = "create" | "join";

export default function OnboardingPage() {
  const router = useRouter();
  const [mode, setMode] = useState<Mode>("create");
  const [name, setName] = useState("");
  const [code, setCode] = useState("");
  const [error, setError] = useState<string | null>(null);

  async function submit(event: React.FormEvent) {
    event.preventDefault();
    setError(null);
    try {
      if (mode === "create") {
        await clientFetch("/households", {
          method: "POST",
          body: JSON.stringify({ name }),
        });
      } else {
        await clientFetch("/households/join", {
          method: "POST",
          body: JSON.stringify({ code }),
        });
      }
      router.push("/");
      router.refresh();
    } catch (caught) {
      setError(caught instanceof ApiError ? caught.message : "Ocurrió un error");
    }
  }

  return (
    <main className="mx-auto flex min-h-[100dvh] max-w-sm flex-col justify-center gap-4 px-4">
      <h1 className="text-2xl font-bold">Tu hogar</h1>

      <div role="tablist" className="flex gap-2">
        <button
          role="tab"
          aria-selected={mode === "create"}
          onClick={() => setMode("create")}
          className={`flex-1 rounded-lg px-3 py-2 ${
            mode === "create" ? "bg-brand text-brand-contrast" : "bg-surface-sunken"
          }`}
        >
          Crear hogar
        </button>
        <button
          role="tab"
          aria-selected={mode === "join"}
          onClick={() => setMode("join")}
          className={`flex-1 rounded-lg px-3 py-2 ${
            mode === "join" ? "bg-brand text-brand-contrast" : "bg-surface-sunken"
          }`}
        >
          Unirme con código
        </button>
      </div>

      <form onSubmit={submit} className="flex flex-col gap-3">
        {mode === "create" ? (
          <Input
            label="Nombre del hogar"
            placeholder="Familia Hernández"
            required
            value={name}
            onChange={(e) => setName(e.target.value)}
          />
        ) : (
          <Input
            label="Código de invitación"
            required
            maxLength={8}
            autoCapitalize="characters"
            autoCorrect="off"
            spellCheck={false}
            className="tabular text-center text-2xl tracking-widest"
            value={code}
            /* Codes are printed uppercase and read aloud; accept any case. */
            onChange={(e) => setCode(e.target.value.toUpperCase())}
          />
        )}
        {error ? (
          <p role="alert" className="text-sm text-danger">
            {error}
          </p>
        ) : null}
        <Button type="submit">{mode === "create" ? "Crear" : "Unirme"}</Button>
      </form>
    </main>
  );
}
```

```tsx
"use client";

import { useEffect, useRef } from "react";

/** Full-screen on mobile, centred modal from md up (design-system.md §2). */
export function Sheet({
  open,
  onClose,
  title,
  children,
}: {
  open: boolean;
  onClose: () => void;
  title: string;
  children: React.ReactNode;
}) {
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!open) return;
    function onKey(event: KeyboardEvent) {
      if (event.key === "Escape") onClose();
    }
    document.addEventListener("keydown", onKey);
    ref.current?.focus();
    return () => document.removeEventListener("keydown", onKey);
  }, [open, onClose]);

  if (!open) return null;

  return (
    <div className="fixed inset-0 z-20 flex items-end justify-center bg-black/40 md:items-center">
      <div
        ref={ref}
        role="dialog"
        aria-modal="true"
        aria-label={title}
        tabIndex={-1}
        className="safe-bottom max-h-[90dvh] w-full overflow-y-auto rounded-t-2xl bg-surface p-4 md:max-w-lg md:rounded-2xl"
      >
        <div className="mb-3 flex items-center justify-between">
          <h2 className="text-lg font-semibold">{title}</h2>
          <button onClick={onClose} aria-label="Cerrar" className="text-text-muted">
            ✕
          </button>
        </div>
        {children}
      </div>
    </div>
  );
}
```

```tsx
"use client";

import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { useState } from "react";

import { MoneyInput } from "@/components/ui/MoneyInput";
import { Button } from "@/components/ui/Button";
import { Input } from "@/components/ui/Input";
import { clientFetch } from "@/lib/api/client";

interface Category {
  id: string;
  name: string;
  kind: string;
}

export function TransactionForm({
  kind,
  currency,
  onDone,
}: {
  kind: "income" | "expense";
  currency: string;
  onDone: () => void;
}) {
  const queryClient = useQueryClient();
  const [amount, setAmount] = useState(0);
  const [categoryId, setCategoryId] = useState("");
  const [occurredOn, setOccurredOn] = useState(new Date().toISOString().slice(0, 10));
  const [note, setNote] = useState("");

  const categories = useQuery({
    queryKey: ["categories", kind],
    queryFn: () => clientFetch<Category[]>(`/categories?kind=${kind}`),
  });

  const create = useMutation({
    mutationFn: () =>
      clientFetch("/me/transactions", {
        method: "POST",
        body: JSON.stringify({
          kind,
          category_id: categoryId,
          amount_minor: amount,
          occurred_on: occurredOn,
          note: note || null,
        }),
      }),
    onSuccess: async () => {
      await queryClient.invalidateQueries({ queryKey: ["transactions"] });
      onDone();
    },
  });

  return (
    <form
      className="flex flex-col gap-3"
      onSubmit={(event) => {
        event.preventDefault();
        create.mutate();
      }}
    >
      <MoneyInput label="Monto" value={amount} onChange={setAmount} currency={currency} required />

      <div className="flex flex-col gap-1">
        <label htmlFor="category" className="text-sm font-medium text-text-muted">
          Categoría
        </label>
        <select
          id="category"
          required
          value={categoryId}
          onChange={(event) => setCategoryId(event.target.value)}
          className="rounded-lg border border-border bg-surface px-3 py-3"
        >
          <option value="">Selecciona…</option>
          {categories.data?.map((category) => (
            <option key={category.id} value={category.id}>
              {category.name}
            </option>
          ))}
        </select>
      </div>

      {/* Native date input: iOS's own picker beats anything custom. */}
      <Input
        label="Fecha"
        type="date"
        required
        value={occurredOn}
        onChange={(event) => setOccurredOn(event.target.value)}
      />
      <Input
        label="Nota (opcional)"
        value={note}
        onChange={(event) => setNote(event.target.value)}
      />

      {create.isError ? (
        <p role="alert" className="text-sm text-danger">
          {(create.error as Error).message}
        </p>
      ) : null}

      <Button type="submit" disabled={create.isPending || amount <= 0 || !categoryId}>
        {create.isPending ? "Guardando…" : "Guardar"}

  );
}
```

```js
/**
 * App shell only.
 *
 * API responses are NEVER cached. A cached financial response outlives the
 * visibility setting that permitted it — a member who switches to Private
 * would still have their figures sitting in another member's browser cache.
 */

const CACHE = "family-hub-shell-v1";
const SHELL = ["/", "/manifest.webmanifest", "/icon-192.png"];

self.addEventListener("install", (event) => {
  event.waitUntil(caches.open(CACHE).then((cache) => cache.addAll(SHELL)));
});

self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches
      .keys()
      .then((keys) =>
        Promise.all(keys.filter((key) => key !== CACHE).map((key) => caches.delete(key))),
      ),
  );
});

self.addEventListener("fetch", (event) => {
  const url = new URL(event.request.url);

  // Never touch data. Not the proxy, not the API, not the session route.
  if (url.pathname.startsWith("/api/")) {
    return;
  }

  if (event.request.method !== "GET") {
    return;
  }

  event.respondWith(
    caches.match(event.request).then((cached) => {
      if (cached) return cached;
      return fetch(event.request).then((response) => {
        const copy = response.clone();
        caches.open(CACHE).then((cache) => cache.put(event.request, copy));
        return response;
      });
    }),
  );
});
```

```ts
import AxeBuilder from "@axe-core/playwright";
import { expect, test } from "@playwright/test";

const ROUTES = ["/login", "/registro"];

for (const route of ROUTES) {
  test(`${route} has no accessibility violations`, async ({ page }) => {
    await page.goto(route);
    const results = await new AxeBuilder({ page }).analyze();
    expect(results.violations).toEqual([]);
  });

  test(`${route} never scrolls horizontally`, async ({ page }) => {
    for (const width of [375, 768, 1280]) {
      await page.setViewportSize({ width, height: 812 });
      await page.goto(route);
      const overflows = await page.evaluate(
        () => document.documentElement.scrollWidth > document.documentElement.clientWidth,
      );
      expect(overflows, `horizontal overflow at ${width}px`).toBe(false);
    }
  });
}

test("the bottom nav clears the safe area on mobile", async ({ page }) => {
  await page.setViewportSize({ width: 375, height: 812 });
  await page.goto("/login");
  const usesVh = await page.evaluate(() =>
    [...document.styleSheets]
      .flatMap((sheet) => {
        try {
          return [...sheet.cssRules].map((rule) => rule.cssText);
        } catch {
          return [];
        }
      })
      .some((text) => /:\s*100vh/.test(text)),
  );
  // 100vh on iOS Safari is the height WITHOUT the toolbar.
  expect(usesVh).toBe(false);
});
```
